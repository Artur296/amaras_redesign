# Current Task

## What We're Building
- **Внутренний CRM-портал для сотрудников и администратора («Портал»)**:
  - Адрес: `/portal`, вход: `/portal/login`
  - Учётные данные администратора: `admin` / `amaras_big_secret2026$`
  - Регистрация сотрудников: заявка создаётся со статусом `pending`, вход возможен только после подтверждения администратором (`approved`).
  - Разграничение прав:
    - Работники видят **только свой список** добавленных клиентов (`createdByUserId`).
    - Работники **не могут редактировать или удалять** записи клиентов.
    - Только администратор может редактировать, удалять клиентов, а также модерировать (одобрять / отклонять / удалять) учётные записи сотрудников.
  - Таблица в стиле Excel:
    - Полноэкранный табличный вид с ячейками, цветовыми бейджами статусов заявки и оплат.
    - Быстрый поиск по всем полям (имя, телефон, направление, даты, менеджер, статус, заметки).
    - Фильтрация по статусу, датам и менеджеру.
    - Прямой переход в WhatsApp и Telegram по клику на номер/логин.
    - Экспорт всей таблицы в реальный файл Excel (CSV с поддержкой кириллицы UTF-8 BOM и разделителем-точкой с запятой).
  - Полная изоляция от основной админ-панели сайта (`/admin`): независимая cookie-сессия (`amaras_portal_session`), раздельные API и хранилища данных.
